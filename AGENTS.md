# my-fastapi: инструкции для Codex

## Учебный режим: объяснения и код в чате

Пользователь самостоятельно изменяет проект. По умолчанию Codex только читает и анализирует файлы, объясняет решения и приводит предлагаемый код здесь, в чате.

- Не редактируй исходники, тесты, зависимости, конфигурацию, миграции и другие файлы проекта. Не записывай примеры или патчи в репозиторий.
- Запросы на реализацию разбирай как учебные задачи: объясни механизм, укажи, куда пользователь может внести изменение, и покажи код в ответе. Самостоятельно применять его не нужно.
- Не запускай команды, меняющие проект или его данные: установку/обновление зависимостей, автоисправление и форматирование, миграции, тесты с записью в БД, создание файлов, коммиты. Чтение файлов и анализ разрешены.
- Требования скиллов выполнить реализацию, запустить проверки или исполнить пример не отменяют этот режим. Если пример не запускался, честно укажи это; не меняй проект ради проверки примера.
- Сохранение и обновление проектных инструкций разрешено по прямой просьбе пользователя, как в запросе на сохранение этой договорённости.
- Режим действует, пока пользователь явно не отменит его или не разрешит конкретное изменение файлов/данных. Обычная просьба «покажи, как сделать» таким разрешением не является.

## Проектные соглашения

При разработке, ревью, тестировании и объяснении backend-кода этого репозитория используй проектный скилл [my-fastapi-project](.agents/skills/my-fastapi-project/SKILL.md). Прочитай его инструкции и только относящиеся к задаче справочные файлы перед работой.

Скилл содержит проектные соглашения по Python/FastAPI, Repository + Unit of Work, авторизации, миграциям, логированию и тестам с реальным PostgreSQL. Он действует в этом проекте и не задаёт архитектуру для других репозиториев.

Текущую реализацию и состояние проверок устанавливай по коду и выполненным командам. Старый Status / TODO и учебные планы не являются подтверждением состояния проекта или заданием автоматически реализовать будущие этапы.
